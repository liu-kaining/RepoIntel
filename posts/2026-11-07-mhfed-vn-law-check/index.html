解决的工程痛点

越南2025-2026多部数字法律集中生效，小团队开发网站/app时不知道哪些表单、追踪脚本和聊天机器人需要同意与披露，人工翻法条成本高且易漏，发布前常处于违规风险。

⚙

CTO 级技术审计

项目以 SKILL.md 为 agent 指令入口，要求先跑 scripts/scan.sh <dir|URL> 得到 LEVEL 信号，再按 references/00-triage.md 分级打开对应 checklist；scripts/fetch-site.sh 负责 URL 模式抓取公开页面与 JS，tools/sync.sh 从根 AGENTS.md/DISCLAIMER 等生成 Claude/Cursor/Windsurf/Cline 多份 rule，CI 用 tests/run.sh 对 fixtures 验证 LEVEL 输出。

多工具同步机制。tools/sync.sh 单源生成并 diff 检查多 agent rule，install.sh 用 MARK 指针插入 .vn-law-check/ 且不覆盖用户文件，降低安装维护成本。

诚实标注未验证法律条文。references/04-consumer-protection.md 多处标注“CHƯA XÁC MINH”，SKILL.md 强制不编造条款和罚款，降低误报的法律风险。

未审阅到 scripts/scan.sh 实现，无法判断 grep 信号、LEVEL 分级和 APP/AI 检测的准确性；tests/run.sh 只对 fixtures 的 LEVEL= 关键字做匹配，覆盖较浅。

scripts/fetch-site.sh 的 resolve 用 [[ "$href" == "$origin"* ]] 判断同域，没有 / 或端口边界，https://example.com.evil.com 可通过前缀匹配拉取站外内容；此外内联 JS 和动态脚本不在 <script src> 提取范围。

作为发布前初步自查和报告草稿生成工具使用；法律条款更新应走 PR 复核，核心扫描逻辑补充 fixture 覆盖并修复同域判断边界。

⚠

隐藏风险与雷点

  • 大量“CHƯA XÁC MINH”条文，若误当终局结论可能造成罚款误判；须律师复核（DISCLAIMER.md）。
  • fetch-site.sh 同域前缀匹配可绕过域名边界，建议改为 ^${origin}(/|$)。
  • 未审阅核心 scan.sh，CI 仅验证 LEVEL 关键词，可能漏报动态渲染或内联脚本的风险。
  • summary 过长，可能含废话
◈

生态与商业价值

越南数字法律切换期，这款工具可作为法律科技获客入口或内嵌到建站/代理平台；但当前免费、无法律背书，直接变现需引入认证律师或SaaS报告服务。
